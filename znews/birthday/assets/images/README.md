# Birthday Universe image assets

`moon-surface-v1.webp` was generated with OpenAI's built-in image generation
tool on 2026-09-20. The prompt requested a photorealistic, seamless,
equirectangular lunar albedo texture with no stars, text, border or directional
shadow. The generated PNG was resized and encoded locally as a 1536 x 768 WebP
texture for the self-hosted Three.js moon.

The texture is decorative. It is not an astronomical moon-phase record or a
claim of ownership over any real celestial object.
